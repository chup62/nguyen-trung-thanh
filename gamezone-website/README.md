# GameZone Website

Dự án này là hệ thống **quản lý website game**, được xây dựng với mục tiêu *tối ưu hóa trải nghiệm người dùng*.

| Thư mục | Nội dung |
| :--- | :--- |
| docs | Chứa tài liệu hướng dẫn và cập nhật |
| media | Chứa các file hình ảnh, logo |
| logs | Chứa các file báo cáo và log hệ thống |
